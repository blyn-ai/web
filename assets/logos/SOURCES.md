# Logo sources — "Markets and infrastructure" strip

Every file below was downloaded from the vendor's own brand, press or product
page and is byte-identical to what the vendor publishes. Nothing was drawn,
traced, recoloured, cropped or approximated.

`.tr-mono` in `site.css` is a bordered plate that centres the image at a shared
height; it sets `color` for text only and applies no filter, mask or fill
override, so every logo renders in its own official colours. No item drops the
plate.

## Rendered as text, no logo file

Rule 2 of the delta: where no official SVG could be obtained, the item renders
as `span.tr-name` only. No look-alike was substituted.

| Item | Reason |
|---|---|
| Kraken | No brand or media-assets page found (`kraken.com/brand` and `kraken.com/media-assets` both 404). The site ships its logo as inline SVG only, with no downloadable file. |
| Hyperliquid | No brand page found (`hyperfoundation.org/brand` 404). The site serves only content-hashed build assets with opaque names, not a published logo file. |
| Cloudflare | The official press kit (https://www.cloudflare.com/press-kit/) offers `Logos.zip`, which contains raster only — `CF Logo 2.jpg` and `CF-Logo 1.png`. The single SVG on that page is the white-on-transparent variant, unusable on this page's light background and forbidden to recolour. |
