# MB „BlynAI" — сводка проекта

> Контекст для загрузки в отдельный AI-проект. Не код-ревью и не документация для
> разработчика. Аудитория — не программист: читает, чтобы понимать, что делать
> дальше по продукту. Актуально на 2026-08-28.

## 1. Что это за проект

blynai.eu — публичный сайт литовской компании MB „BlynAI" (торговое имя
*BlynAI Systems*, дескриптор *L&D Finance Lab*, где L&D = Learn & Develop).
Это не продуктовый сервис, а **лицо компании**: двухчленная лаборатория
финансовых систем, которая пишет ПО для алгоритмической торговли, гоняет его в
живом крипторынке на собственные деньги и публикует каждое решение бота,
включая ошибки. Сайт сделан, чтобы говорить с двумя аудиториями — фондами
(EU-гранты, MTEP) и инвесторами/партнёрами — и доказать делом: «мы не предлагаем
ИИ-систему для торговли, мы уже проводим эксперимент». Клиентских денег компания
не берёт и не возьмёт — это заявлено юридически и повторяется на странице.

## 2. Что работает сейчас

- **Сайт**: одна статическая HTML-страница, без сборки и фреймворков. Хостится
  на **Cloudflare Pages** (проект `blynai-web`, привязан к GitHub-репозиторию
  `blyn-ai/web`, автодеплой на каждый push). Живёт на `blynai.eu`.
- **Две языковые версии**: английская на корне `/`, литовская на `/lt/`,
  переключатель в шапке. Переключатель, sitemap и hreflang настроены.
- **Живая телеметрия**: полоса на странице тянет реальные цифры из API журнала
  (`/api/public-stats` на `blynai.meetluko.eu`, запасной `blynai.bykovas.lt`) —
  последний цикл, число рынков, всего решений, время по Вильнюсу. Если API
  недоступен — показываются прочерки, выдуманных чисел нет.
- **Две живые торговые инстанции бота**: LUKO (`blynai.meetluko.eu`) и BYKO
  (`blynai.bykovas.lt`) — один код, разные счета и конфигурации, общие рыночные
  данные. Торгуют фьючерсами на бирже **Kraken**, цикл решений — каждые 120
  секунд, ~150+ рынков.
- **Продукт CryptoSmith X**: отдельная секция на сайте со ссылкой на сам бот
  (`cryptosmithx.blynai.eu`, отвечает) и на открытый код
  (`github.com/blyn-ai/CryptoSmith-X`). Само приложение — самостоятельный
  продукт с логином, в ранней стадии.
- **Подписанный учредительный акт** (PDF с квалифицированными э-подписями от
  2026-08-24) — выложен и доступен со страницы.
- **API телеметрии** (`/api/public-stats` и др.) живёт в отдельном репозитории
  `trading-bot`, задеплоено в проде за Traefik.

## 3. Что не доделано или в работе

- **CryptoSmith X как продукт** — самое сырое. Экран `/config` (Parametrai)
  отдаёт 404, ссылка стоит «на вырост». Логин, регистрация («Registracija į
  alfą»), страница аккаунта — в разработке.
- **Собственный домен для API** — сейчас телеметрию отдаёт домен журнала BlynAI;
  для продукта с логином логичнее отдельный (`api.blynai.eu` или
  `api.cryptosmith…`). Не сделано.
- **Отказоустойчивость API** — запасной домен спасает от сетевых проблем, но за
  обоими адресами **один контейнер**; при его падении оба умрут вместе. Второй
  экземпляр не поднят.
- **Документация CryptoSmith X** — страница-заглушка `dokumentacija/` в
  репозитории есть, но с сайта на неё не ссылаются, пока писать нечего.
- **Данные графика и позиций в интерфейсе бота** — источники в API найдены
  (кривая портфеля, открытые позиции, состояние «нет позиций»), но во фронт
  продукта ещё не вшиты.
- **SEO-переиндексация** — Google ещё держит старый литовский заголовок на
  английском корне; sitemap подан, ждём переобхода. Действие на стороне
  владельца (Search Console).
- **Google Search Console / Cloudflare** — рекомендованные ручные шаги
  (переиндексация, проверка Browser Cache TTL и Bot Fight Mode) висят за
  владельцем.
- **Несколько заглушек-адресов**: почты `partnerships@blynai.eu` /
  `research@blynai.eu` (всё падает на `@blynai.eu`), дата регистрации компании
  (`suteikiamas įregistravus`).

## 4. Ключевые решения и ограничения

- **Литовский — авторитетный язык.** Английский — зеркало для фондов/инвесторов;
  юридический дисклеймер нельзя машинно переводить, литовская версия имеет
  юридическую силу.
- **Никаких выдуманных цифр.** Числа либо замерены (живой API), либо посчитаны из
  конфигурации с пометкой. Прочерки вместо чисел, если данных нет. Проверять всё
  против кода/API перед публикацией.
- **Бренд-правила жёсткие** (нельзя ломать): нет чисел доходности/P&L нигде; нет
  зелёного и красного (торговый бренд, сознательно отказавшийся от рыночных
  цветов); нет набора иконок и эмодзи; золото-фиолетовый градиент — только в
  четырёх местах; коин-марки LUKO/BYKO не перекрашивать; дисклеймер — дословно.
- **Роль ИИ честно ограничена**: языковая модель только выбирает список
  наблюдаемых пар (watchlist); торговое решение принимают правила, без модели
  система работает. Это важно и юридически, и для доверия.
- **Продукт vs лаборатория.** CryptoSmith X добавлен на сайт по решению
  владельца, хотя исходный дизайн-хендофф этого не предполагал (запрещал ссылки
  на продукт). Это сознательное отступление.
- **Никаких зависимостей в сайте** — статика, ручной или авто-деплой, минимум
  инлайн-скриптов (только диалог дисклеймера и запрос телеметрии).

## 5. Словарь терминов

- **MB „BlynAI"** — юридическое название компании (mažoji bendrija — малое
  товарищество, литовская форма). *BlynAI Systems* — торговое имя,
  *L&D Finance Lab* — дескриптор.
- **L&D** — Learn & Develop (учиться, создавая). Раньше читалось как
  Lukas & Denisas (имена двух учредителей) — теперь официально Learn & Develop.
- **BLYN / AI** — расшифровка названия: BLYN = Block Ledger Yardstick
  Normalization (что измеряется), AI = Algorithmic Inference (что из этого
  делается). По-литовски слово читается как «blynai» (блины) — сознательная
  самоирония бренда.
- **LUKO** и **BYKO** — две независимые торговые инстанции бота (по учредителям:
  Lukas / Denisas), один код, разные счета.
- **CryptoSmith X** — продукт компании: бесплатная опенсорс-платформа для
  построения и запуска торговых стратегий, «тот же стенд, на котором лаборатория
  изучает свою программу».
- **Стенд / Programa Nr. 1** — первая программа лаборатории: экспериментальный
  алгоритмический торговый стенд в живом крипторынке.
- **Телеметрия** — публичный поток данных из журнала бота (циклы, рынки,
  решения), которым питаются и журналы, и сайт.
- **trading-bot** — отдельный репозиторий с кодом бота и API; `blyn-ai/web` —
  репозиторий сайта.
