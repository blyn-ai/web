Use StatBar directly under a dark hero to state legal form, membership and licence without a table.

```jsx
<StatBar items={[
  { label: "Teisinė forma", value: "Mažoji bendrija" },
  { label: "Nariai", value: "2 · po 50 %" },
  { label: "Kodo licencija", value: "Atvirasis kodas" }
]} />
```

- Values are short noun phrases in Space Grotesk 600/18. Never percentages of made-up performance.
