Use EquityCurve when a surface needs the brand's one illustrative device — a rising ledger line. It is never a real chart; never label its axes.

```jsx
<div style={{ position: "relative" }}>
  <EquityCurve variant="band" style={{ position: "absolute", left: 0, bottom: 0 }} />
</div>
```

- `variant="full"` sits behind headline type on social cards; keep type clear of the line's right shoulder.
- Absolutely position it; it always bleeds to both edges.
